This app searches content that has been ingested locally and pushed to your Qdrant index. To get started, run the following commands in your terminal:

1
Clone the repo and install dependencies
git clone https://github.com/Shashank17singh/Youtube-Scrapper && cd Youtube-Scrapper
uv sync
2
Copy .env.example and fill in your API keys
cp .env.example .env
3
Ingest a YouTube playlist
uv run ytrag ingest --playlist "https://youtube.com/playlist?list=YOUR_PLAYLIST_ID"
4
Search instantly once done - no restart needed
Click any result to play
from that exact moment.
